# mikro_hydra
╔════════════════════════════╗
║     *   mikro hydra   *    ║
╚════════════════════════════╝
Простая программа для поиска слов в текстовых файлах (типа мини-брутфорс).

## 📥 Установка

1. Скачай файл `Program.cs`
2. Скомпилируй
3. Запусти


## ✨ Что умеет

- Ищет слово без учета регистра (Привет = привет)
- Показывает номер строки где нашлось
- Считает количество попыток
- Показывает прогресс (каждые 100 слов)
- Зеленым подсвечивает если нашло, красным если нет

## ⚠️ Если файл не находится

Вводи полный путь, например:
- `/home/!!!user(восклицательные знаки не нужно)/VSCode/sharp/text.txt` (Linux)
- `C:\Users\!!!user(восклицательные знаки не нужно)\Desktop\text.txt` (Windows)

## 🛠 Требования

- .NET 6.0 или выше
- Любая ОС (Windows, Linux, Mac)

Для учебы, не для взлома!
